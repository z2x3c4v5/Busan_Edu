# 션이와 함께! 부산을 말하다 — Speaking Challenge

부산교육한마당 부스 체험용 웹 앱입니다. 학생이 **주제(명소·음식·축제) → 난이도(초급·중급·고급) → 문장 최대 5개**를 고르고,
듣고 따라 말한 뒤 마이크로 녹음하면 AI 음성 인식으로 **정확도(AI가 알아들은 정도)**를 보여 줍니다.

## 실행 / 배포
- 빌드 없이 정적 파일만으로 동작합니다.
- 마이크는 **https**(또는 localhost)에서만 쓸 수 있어요. GitHub 저장소 → Settings → Pages → Branch 선택으로 배포하면 됩니다.
- 로컬 테스트: `python3 -m http.server` 후 `http://localhost:8000`

## 부스 운영 팁
- 브라우저: **Chrome**(PC·안드로이드) 또는 Edge, iPad는 Safari. Firefox는 음성 인식 미지원.
- **인터넷 필수** — 브라우저 음성 인식은 온라인 서버를 사용합니다.
- 행사 전에 기기에서 한 번 마이크 권한을 허용해 두세요.
- 시끄러운 행사장에서는 **헤드셋 마이크**를 권장합니다.
- 공용 기기용: 학생 기록은 저장하지 않고, 2분간 입력이 없으면 처음 화면으로 돌아갑니다.
- 안드로이드에서는 마이크 충돌을 막기 위해 "내 목소리 듣기"(녹음 재생)가 꺼집니다.

## 파일 구조
| 파일 | 내용 |
|---|---|
| `js/data.js` | 주제 × 난이도별 문장(영어/우리말). **문장 수정은 여기서** |
| `js/lexicon.js` | 한국어 고유명사: 영어 음성용 발음 + 음성 인식 허용 표기 |
| `js/score.js` | 단어 단위 정렬 채점 (축약형·숫자 통일, 고유명사 너그럽게) |
| `js/speech.js` | 듣기(TTS)와 말하기(음성 인식·녹음) |
| `js/app.js` | 화면 흐름 |
| `images/` | 캐릭터 션이 이미지 (부산광역시교육청 캐릭터) |

## 채점 기준
- 단어별: 🟢 맞음 / 🟡 비슷함 / 🔴 놓침
- 별: 90% 이상 ★★★, 70% 이상 ★★, 40% 이상 ★
- 정밀한 발음 평가가 아니라 "AI가 알아들은 정도"입니다.
